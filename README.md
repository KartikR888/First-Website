# My First Website

A clean, responsive single-page personal site and portfolio project built by **Kartik R** using semantic HTML5 and modern CSS3. This project highlights core web development fundamentals, responsive grid design, micro-interactions, and native media integration.

---

## 🚀 Features

* **Developer Profile Header:** Clean introductory section featuring links to GitHub, LinkedIn, and Google Developer profile pages.
* **Resource Quick Links:** Curated links directing to MDN Web Docs for HTML, CSS, and JavaScript.
* **Responsive Image Gallery:** A 3×2 CSS Grid layout showcasing scenic landscape imagery with smooth hover zoom effects.
* **Adaptive Layout:** Fully responsive breakpoints that adjust the gallery grid from 3 columns on desktops to 2 columns on tablets, and a single column on mobile devices.
* **Embedded Media Showcase:** Native HTML5 `<video>` player integration supporting in-browser playback controls.
* **Interactive UI Elements:** Styled badges, smooth transitions, and hover animations built with vanilla CSS.

---

## 🛠️ Built With

* **HTML5:** Semantic document structure, links, media embeds, and accessibility markup.
* **CSS3:** Custom properties (CSS variables), CSS Grid, Flexbox, media queries, and transition animations.

## 🖥️ Getting Started

To view and run this project locally:

1. Clone or download the repository to your local machine.
2. Open `FirstWebsite.html` directly in any modern web browser (Google Chrome, Firefox, Safari, Edge).
   ```bash
   # On macOS
   open FirstWebsite.html

   # On Linux
   xdg-open FirstWebsite.html

   # On Windows
   start FirstWebsite.html
   ```
